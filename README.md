# LearnSphere
LearnSphere is a centralized web application designed to bridge the gap between students and mentors. Unlike automated AI systems, this platform focuses on human expertise. It provides a structured environment where students can seek career or technical advice, and mentors can manage and respond to these queries through a specialized dashboard.
A simple and beautiful platform where Students can ask questions and Mentors can provide expert advice.

🚀 How to Run
Install the requirements:

Bash

pip install streamlit pandas
Start the app:

Bash

streamlit run app.py
🔑 Key Features
Login System: Private accounts for Students and Mentors.

Ask & Answer: Students post questions; Mentors reply directly.

Admin View: A special dashboard to see how many people are using the app.

Smart Greetings: The app says "Good Morning" or "Good Evening" based on your time!

📂 Files in this Project
app.py - The main code.

requirements.txt - List of tools needed.

users.csv - Stores login details.

mentor_requests.csv - Stores student questions.

mentor_answers.csv - Stores mentor replies.
